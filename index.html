Mulai dari sini.

Dari download sampai siap dibuka. Cukup ikuti langkah berikut.

  1. Klik Download untuk Windows di atas.
  2. Tunggu hingga file Sela_0.1.2_x64-setup.exe selesai diunduh.
  3. Buka folder Downloads, lalu klik dua kali file installer.
  4. Ikuti petunjuk instalasi sampai selesai, lalu klik Finish.
  5. Buka Sela dari Start Menu atau ikon di Desktop.

Cara Install

  1. Klik tombol Download Sela untuk Windows di atas.
  2. Tunggu sampai file Sela_0.1.0_x64-setup.exe selesai diunduh.
  3. Buka file tersebut (klik dua kali) dari folder Downloads.
  4. Ikuti petunjuk di layar sampai selesai, lalu klik Finish.
  5. Buka Sela dari Start Menu atau ikon di Desktop.
